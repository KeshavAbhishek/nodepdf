# MergePDF Pro

A web application to merge two or more PDF files using the `pdf-lib` Node.js library.  

Live at: [https://mergepdf.crystaled.dev](https://mergepdf.crystaled.dev)

---

## Features

- Merge **up to 50 PDF files** at once.  
- Light mode & Dark mode themes for better viewing experience.  
- Uploaded files are **automatically deleted** from server right after the merged PDF is downloaded, ensuring privacy.  

---

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, `pdf-lib`  

---

## Installation & Setup

If you want to run this locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/KeshavAbhishek/nodepdf.git
   cd nodepdf
```
